# Iconos de redes sociales

Estos SVG contienen únicamente el símbolo de cada marca, sin nombre ni logotipo horizontal, para mostrarse junto al texto accesible del enlace en la sección «Encuéntrame».

Los archivos se descargaron desde [Simple Icons](https://simpleicons.org/) con los colores asociados a cada marca. Los nombres y marcas pertenecen a sus respectivos titulares.
