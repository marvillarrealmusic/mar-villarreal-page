# Mar Villarreal Sanity Studio

This folder contains a standalone Sanity Studio for the Mar Villarreal website.

## Quick start

1. Create a Sanity project at https://www.sanity.io/manage
2. Copy `.env.example` to `.env` and replace the values with your project ID and dataset
3. Install dependencies with `npm install`
4. Start the Studio with `npm run dev`

## Content model

The Studio includes schemas for:
- siteSettings
- homePage
- artistProfile
- musicRelease
- video
- event
- service
- galleryImage
- seo
